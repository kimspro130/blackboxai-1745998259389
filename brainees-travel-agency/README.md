## Hosting on GitHub Pages

You can host this website for free using GitHub Pages by following these steps:

1. Create a GitHub repository (e.g., `brainees-travel-agency`).

2. Clone the repository to your local machine:
   ```
   git clone https://github.com/your-username/brainees-travel-agency.git
   ```

3. Copy all the files from this project folder (`brainees-travel-agency`) into the cloned repository folder.

4. Commit and push the files to GitHub:
   ```
   git add .
   git commit -m "Add Brainees Travel Agency website files"
   git push origin main
   ```

5. On GitHub, go to the repository's **Settings** > **Pages**.

6. Under **Source**, select the branch (usually `main`) and the root folder (`/`).

7. Click **Save**. GitHub Pages will publish your site at:
   ```
   https://your-username.github.io/brainees-travel-agency/
   ```

8. Visit the URL to see your live website.

## Notes

- Make sure your repository is public for GitHub Pages to work without a paid plan.
- You can update the website by pushing new commits to the repository.

Enjoy your hosted Brainees Travel Agency website!
